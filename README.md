# 分屏窗口切换器 · Monitor Alt+Tab

一个免费的 Windows 多显示器窗口切换脚本：**鼠标在哪块屏幕，Alt+Tab 就只切换那块屏幕上的窗口。**

按住 Alt 查看窗口缩略图，使用键盘循环或鼠标点击选择。脚本在本地运行，不发送网络请求，不上传窗口标题或预览画面。

## 能做什么

- **按显示器筛选**：仅显示鼠标所在显示器的候选窗口。
- **窗口卡片预览**：显示缩略图、应用图标和窗口标题；取不到图标时使用通用图标。
- **明确高亮**：待激活窗口显示亮蓝色边框、蓝色加粗标题和 `>` 标记。
- **键盘双向循环**：支持正向、反向、首尾循环和自动翻页，每页最多 8 项。
- **鼠标确认**：点击缩略图、标题或图标直接激活对应窗口。
- **减少闪烁**：同页切换复用界面和缩略图，翻页保留选择器窗口。
- **最小化恢复**：最小化窗口仍可列出，确认后恢复并激活。
- **候选窗口过滤**：排除桌面、任务栏、不可见窗口、工具窗口等，并尝试处理活动弹窗。

跨屏窗口归入与其相交面积最大的显示器；最小化窗口按最小化前的位置归属。这里的“分屏”指多显示器，不是单屏中的分区。

## 常用操作

1. 将鼠标移到目标显示器。
2. **按住 Alt，再按 Tab**，打开选择器。
3. 保持 Alt 按住，用 Tab 或 Shift+Tab 移动高亮。
4. **松开 Alt**，打开高亮窗口；也可以保持 Alt 按住，直接点击目标卡片。

| 操作 | 效果 |
| --- | --- |
| Alt+Tab | 打开选择器并向前选择 |
| 保持 Alt 按住，继续按 Tab | 向前循环，必要时自动翻页 |
| Alt+Shift+Tab | 反向循环 |
| 松开 Alt | 激活高亮窗口 |
| 点击卡片 | 直接激活被点击的窗口 |
| Esc | 取消本轮选择 |

鼠标悬停不会改变选择。顶部数字表示当前条目序号和总数，底部数字表示页码；`Preview unavailable` 表示无法获取预览，仍可按标题选择。

首次按 Alt+Tab 时锁定显示器和窗口列表。本轮移动鼠标不会切换显示器，新开窗口下一轮才加入。窗口已关闭、移到另一屏或变为不可切换状态时，确认可能不执行切换，重新打开选择器即可刷新。

## 本机安装与自动启动

### 安装与目录

从上面的官方链接安装 AutoHotkey v2，或下载 ZIP 并解压。将 [MonitorAltTab.ahk](MonitorAltTab.ahk) 和本 README 放到固定目录。

以下是当前电脑的布局，其他电脑可以使用不同盘符，操作时替换为实际路径：

```text
D:\autohotkey\
├─ v2\
│  └─ AutoHotkey64.exe    # AutoHotkey v2 运行程序
└─ script\
   ├─ MonitorAltTab.ahk  # 窗口切换脚本
   └─ README.md          # 使用说明
```

### 设置登录后自动启动

本机已经使用当前用户的 Windows“启动”文件夹配置自启。其他电脑需单独设置；复制工具文件夹不会一起复制启动项。

1. 按 **Win+R**，输入 `shell:startup`，回车。
2. 在打开的文件夹中右键 → **新建 → 快捷方式**。
3. 将以下完整内容填入“对象的位置”，保留两组双引号：

   ```text
   "D:\autohotkey\v2\AutoHotkey64.exe" "D:\autohotkey\script\MonitorAltTab.ahk"
   ```

4. 名称填写 **分屏窗口切换器**，完成创建。
5. 右键快捷方式 → **属性**，把“起始位置”设置为 `D:\autohotkey\script`。
6. 双击该快捷方式验证可以运行。已有同名启动项时直接修改，不要重复创建。

此方式在**当前用户登录 Windows 后**运行，不是登录前的系统服务，默认不提升权限。移动脚本或运行程序后，应同步更新快捷方式；存放目录必须在登录时可访问。

### 复制到其他电脑

可以复制包含 AutoHotkey 运行程序的整个文件夹，也可以只复制脚本并在新电脑安装 AutoHotkey v2。未安装文件关联时，把 `.ahk` 文件拖到 `AutoHotkey64.exe` 上运行，或按上述方式创建快捷方式。使用不同目录时修改快捷方式路径；新电脑仍需重新配置自启。

## 手动启动、退出和取消自启

### 手动启动与更新

- 已安装 AutoHotkey v2 并关联 `.ahk`：双击脚本。
- 使用 ZIP 版：将脚本拖到 `AutoHotkey64.exe` 上，或双击指向运行程序和脚本的快捷方式。
- 更新：保存新脚本后重新启动同一路径的文件，旧实例会被替换。

避免同时运行不同目录中的多个版本，也不要同时运行其他接管 Alt+Tab 的工具。

### 退出当前运行

在任务栏托盘区找到对应的 AutoHotkey 图标，右键选择 **Exit Monitor Alt+Tab** 或 **Exit**。图标可能位于托盘折叠区。

退出后脚本不再接管 Alt+Tab；退出一次不会取消下次登录自启。

### 取消自启

按 Win+R → 输入 `shell:startup` → 删除 **分屏窗口切换器** 快捷方式。若希望立即停用，还需从托盘退出当前脚本。删除快捷方式不会删除脚本或卸载 AutoHotkey。

## 常见问题

| 问题 | 说明与处理 |
| --- | --- |
| 双击脚本无法运行 | 确认安装的是 AutoHotkey v2；未建立关联时，把脚本拖到 v2 运行程序上 |
| 登录后没有自动启动 | 检查快捷方式的两个路径和“起始位置”，确认存放盘可用；检查 Windows 是否禁用了该启动项 |
| 仍显示系统 Alt+Tab | 确认脚本已运行，并检查是否有其他快捷键工具冲突 |
| 鼠标点击前选择器就消失 | 松开 Alt 本身会确认，点击时应继续按住 Alt |
| 不清楚哪个窗口会打开 | 查看亮蓝色边框、蓝色加粗标题及 `>` 标记；它们对应松开 Alt 后的目标 |
| 跨屏窗口出现在另一块屏幕 | 按最大相交面积归属；完整移到目标屏幕后重新打开选择器 |
| 预览黑屏、冻结或不可用 | 部分最小化、GPU、受保护视频和远程窗口存在限制；可通过图标、标题选择 |
| 管理员程序无法激活 | 普通权限脚本可能受权限隔离限制；确有需要可手动以管理员身份运行，自启项默认不提升权限 |
| 右 Alt 不生效 | 部分布局的右 Alt 是 AltGr，优先使用左 Alt |
| 报错或异常 | 保存错误内容、行号及复现步骤；从托盘退出可停止接管，再排查脚本版本和环境 |

当前实现不完全复制系统原生 Alt+Tab 的排序、动画和分组；浏览器按窗口列出，不逐标签页列出。虚拟桌面过滤依赖 DWM 隐藏标记，特殊弹窗可能遗漏或重复。混合 DPI、热插拔、独占全屏游戏和 UAC 安全桌面存在限制，遇到显示器变化可按 Esc 取消后重试。
